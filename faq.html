Questions

Before you buy.

The things engineers ask most often. If your question is not here, get in touch before buying rather than after.

The packs

Which national annex does the Eurocode 2 pack use?+

The base sheet uses the UK National Annex values, and the Parameters tab shows the EN recommended value alongside the UK NA value for every Nationally Determined Parameter. Switching one cell changes the whole workbook. If you need a different annex's parameters, get in touch before buying and this can be adjusted.

Which load combinations does the ACI 318 pack use?+

The sheets work to ACI 318-19's basic strength-design combinations, U = 1.4D and U = 1.2D + 1.6L, both taken from the Parameters tab so you can change the factors. Wind, seismic and snow combinations are outside the scope of these sheets.

Which units does each pack use?+

The Eurocode 2 pack is metric — millimetres, kilonewtons and N/mm². The ACI 318 pack is US customary — inches, kips and psi — because ACI 318-19's numerical coefficients are written for those units, so the formulas appear exactly as the code writes them.

Which elements are covered?+

Both packs cover singly and doubly reinforced rectangular beams, one-way and two-way solid slabs, braced rectangular columns and isolated pad footings, plus a parameters tab and a notes and references tab. Flanged sections, torsion, biaxial bending, fire and seismic detailing are not covered.

Do you offer a bundle of both packs?+

Not yet — Eurocode 2 and ACI 318 are sold separately for now. Get in touch if you need both and would like them priced together.

Using the sheets

Are the sheets suitable for submission to a checking engineer?+

They are built to show every step of the calculation with its clause or section reference, which is what most checkers ask for — but you remain responsible for verifying the output against your own project's specific requirements.

What do I actually receive?+

A single .xlsx workbook, emailed to you automatically after payment. Open formulas throughout, no macros, no password-locked cells and no hidden sheets — you can read every calculation before you trust it.

Which version of Excel do I need?+

Anything that opens .xlsx and supports ordinary worksheet functions. There are no macros, so there is nothing to enable and no security prompt. The sheets also open in LibreOffice Calc, though the interaction chart on the column tab may render slightly differently.

Can I use one pack on more than one project?+

Yes. The licence is per user, not per project — use it on as many jobs as you like. Please do not redistribute the file or share it across a team; buy a copy per engineer instead.

Do I get updates if the code changes?+

Corrections and improvements to the edition you bought are sent to the same email address at no charge. A move to a new edition of the code would be a new product.
